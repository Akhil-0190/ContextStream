Set up the local service

  1. Start the service with npm start.
  2. Open this site at http://localhost:8080.
  3. Add Gemini and search-provider keys in Provider key pool.
  4. Open brave://extensions or chrome://extensions.
  5. Enable Developer mode → Load unpacked → choose extension.

Frame analysis starts only after you choose it. Product data is fetched only after you select an object. Retailers are the source of truth for price and availability.

Local developer setup

Provider key pool

Add any number of Gemini, Brave Search, SerpApi, SearchApi.io, and Serper keys. Keys are encrypted on this local server, masked in this page, and never sent to the browser extension. Give keys from the same quota/project the same quota group so cooldowns are shared correctly.

SearchApi.io and Serper can add alternate Google web and Shopping retrieval. SerpApi remains the visual Lens provider because its upload flow accepts the private crop directly. SearchApi Lens needs a publicly reachable image URL, so ContextStream does not send frames to a separate image host automatically.

This key manager is disabled on Cloud Run. For a deployed service, configure secrets through Google Cloud Secret Manager.
